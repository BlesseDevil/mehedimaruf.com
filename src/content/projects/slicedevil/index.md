Cropping a photo into a circle for a profile picture, or into a rounded square for an app icon, usually means uploading it to a website you have never heard of. SliceDevil does the same job without the upload: the image never leaves your device.

## What it does

- **Any shape.** Circle, ellipse, square, rounded rectangle, pill or a free rectangle.
- **Any format.** Export to PNG, WebP, JPEG, ICO or SVG, at any resolution.
- **Nothing is uploaded.** All the work happens in the browser. After the first load it needs no network at all.
- **Installable.** It is a progressive web app, so it can be added to a phone or desktop as an app and used offline.
- **Fast to start.** Drop an image on the window, paste one with Ctrl+V, or open a file.

There is also a single-file build: one self-contained HTML file that works by double-clicking it, with no server and no dependencies.

Free and open source under the AGPL.
